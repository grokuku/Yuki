Redémarrer Yuki

Le redémarrage interrompt ce qui est en cours : la conversation en cours et les jobs lourds sont arrêtés. Yuki ferme proprement ses connexions puis redémarre son programme.

Yuki redémarre en interne : un superviseur relance le programme dans le conteneur, le conteneur reste en place. Aucune politique de redémarrage Docker n'est nécessaire pour ce bouton.
