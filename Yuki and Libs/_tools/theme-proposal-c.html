Yuki — direction C « neutre teinté maîtrisé + profondeur »

Maquette hors production, focalisée sur la direction C seule, pour la juger en grand. Cinq familles (Indigo, Nuit, Ardoise, Émeraude, Ambre) × deux modes (sombre dominant / clair), un écran complet par famille. Le HTML est autonome : aucune image, aucun script, aucune ressource externe — thème par data-theme + variables CSS, aucun style en ligne.

Correctif 1 — neutre teinté maîtrisé

L'accent est conservé à l'identique (graines de themes.css), mais les surfaces passent à un chroma OKLCH très faible (sombre : 0,007–0,017 ; clair : ≤ 0,032) : le fond redevient quasi neutre et l'accent ressort. Résultat : plus d'effet « même teinte sur toute la page ».

Correctif 2 — profondeur (3 niveaux + survol)

Là où Yuki n'utilise que 2 niveaux, la direction C en pose 3 réels + le survol : surface (fond) → surface-elev (carte) → surface-raised (bloc imbriqué) → hover. Chaque palier est annoté et mesuré (ΔEok).

Correctif 3 — familles distinctes DANS LES DEUX modes

Chaque famille a sa propre clarté de fond : mêmes teintes ou presque (Indigo/Nuit), mais des --surface visiblement différents. Mesure ΔEok fond min — sombre 0.042 (Indigo↔Émeraude, OK), clair 0.045 (Indigo↔Ardoise, OK) — seuil 0.040 = 2× le juste-perceptible 0,020.

Correctif 4 — garde automatique (build cassé si redondance)

La règle de non-redondance (fond ΔEok ≥ 0.04, accent ≥ 0.02, profondeur ≥ 0.02) est vérifiée séparément par mode et le générateur échoue (exit 1) sinon. Preuve de non-vacuité : --selftest-redundant. Accents inchangés.

1 · Les 5 familles en grand — mode sombre (dominant)

Un écran complet par famille. Comparer les fonds et les accents d'un écran à l'autre : Ardoise (plus clair, gris-bleu) ≠ Indigo ≠ Nuit (le plus sombre) ≠ Émeraude ≠ Ambre.

Empilement réel : chaque palier est mesuré par sa distance perceptuelle (ΔEok) au palier inférieur. Un Δ ≈ 0,02 est déjà juste perceptible ; ici les paliers visent nettement plus.

5 · Les 5 familles — mode clair

Mêmes familles, mode clair : la page est teintée (et plus basse en clarté), la carte quasi blanche « pop » dessus. Les 5 fonds se distinguent à l'œil : Ardoise (presque blanche) ≠ Indigo ≠ Ambre ≠ Émeraude ≠ Nuit (le gris le plus profond).

6 · Accents — quatre jeux, comparés en contexte (bouton, lien, badge, anneau, onglet)

Ici on ne parle plus de FOND mais d'ACCENT. Chaque jeu est montré avec les mêmes widgets, dans les deux modes, sur chaque famille : bouton (texte posé sur l'accent), lien, badge, anneau de focus et onglet actif. Sous chaque famille, le contraste mesuré (vert = conforme, rouge = sous le seuil). Seuils : texte/accent ≥ 4,5:1 ; élément non textuel porteur de sens (anneau) ≥ 3:1 ; écart d'accent ≥ 0.04 ; écart de fond ≥ 0.04. Les propositions V1/V2/V3 passent sans violation ; V0 (accents actuels) est la référence non conforme : ses défauts sont mesurés.
