Yuki — variantes de surfaces contre l'effet « monotone »

Maquette hors production, pour choisir sur le visuel. Trois variantes de surfaces (chroma + profondeur de clarté) sont déclinées pour les 3 familles montrées dans les captures (Turquoise, Corail, Ambre) × 2 modes, sur le même écran réaliste. Les accents restent les graines V2 validées lues dans themes.css : le sujet est la surface et la profondeur, pas la couleur d'accent. HTML autonome (ni image, ni script, ni ressource externe).

Le diagnostic, chiffré

Deux causes : lavis d'une teinte (le chroma des surfaces reste quasi constant d'un palier à l'autre — l'écart de chroma interne est minuscule) et profondeur (écarts de clarté entre paliers et entre la page et la bulle d'assistant).

Ce que les variantes changent

A : surfaces quasi neutres (trace de teinte), accent fort. B : teinte plus discrète + profondeur nettement accrue. C : surfaces totalement grises, l'accent fait tout. La clarté de fond propre à chaque famille est conservée en A et B ; C partage une rampe neutre unique.

Seuils de lecture

Texte et texte atténué ≥ 4.5:1 ; texte sur accent ≥ 4.5:1 ; élément non textuel ≥ 3:1 ; écart de profondeur ≥ 0.02 (ΔEok, seuil juste-perceptible). Vert = conforme, rouge = sous le seuil.

Hors périmètre — famille « Matrix »

La famille d'identité matrix (accent néon vert, surfaces monochromes) n'est pas traitée dans ces variantes : ses surfaces ne sont pas teintées vers l'accent, elle échappe donc à la doctrine V2. Aucune de ses valeurs n'est ni dérivée ni modifiée ici.
