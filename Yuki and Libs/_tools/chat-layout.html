États à valider

Compromis signalés :
  • Horodatage (à implémenter plus tard) — en production, un préfixe [horodatage] YYYY-MM-DD HH:mm (heure locale) sera transmis au modèle et stocké en tête de chaque message (Yuki sait enfin « quand » nous sommes) ; il sera aussi visible dans le fil, sous forme compacte « juste l'heure ». Les souvenirs porteront eux aussi leur date (champ at), pour que le rappel mémoire dise « quand ». La maquette n'affiche QUE l'heure sous les bulles et la date complète dans le séparateur de jour.
  • Clic droit vs « ⋯ » — le menu contextuel (clic droit) est le geste le plus rapide à la souris, mais il est invisible (rien n'indique qu'il existe) et inaccessible au doigt (pas de clic droit tactile). Le « ⋯ » discret, révélé au survol (et toujours visible sur la conversation active), rend l'action découvrable et accessible. Les deux ouvrent le même menu (renommer / supprimer).
  • Largeur réglable — le fil remplit l'espace par défaut (--read-max: none). La largeur maximale de lecture est paramétrable : utilisez les boutons du témoin de mesure pour voir l'effet sur la longueur de ligne.
  • Barre latérale — repliée par défaut (56 px), dépliée à 280 px au survol, avec une punaise pour la bloquer dépliée. La conversation se redimensionne en même temps (animation 280 ms sur la largeur).
  • Script INLINE (maquette uniquement) — cette page embarque un <script> inline pour rendre le survol, la punaise, le clic droit et la mesure réellement utilisables. C'est propre à la maquette (hors production) : le code de production respecte la CSP stricte, sans script inline.
