Preview comparative des thèmes — Yuki vs holaf-tokens

Les six panneaux ci-dessous montrent le même écran de configuration de Yuki re-looké avec six jeux de variables : les 2 thèmes maison de Yuki (sombre par défaut, clair via prefers-color-scheme) et les 4 presets de holaf-tokens (dark, light, midnight, slate) projetés sur les 11 variables de Yuki. Les valeurs d'holaf sont lues telles quelles dans holaf-tokens.js ; les variables sans équivalent (--user, --assistant, --ok) sont dérivées avec holaf-color.js (formules dans le rapport). Chaque panneau inclut un aperçu d'une modale holaf-modal et d'un toast holaf-toast aux variables --hm-*/--ht-* correspondantes. Aucune ressource externe : tout est inliné.
